# GigaAM · Живой текст Zoom

Windows-приложение получает **живой звук во время звонка**, распознаёт его
локальной **GigaAM Multilingual 220M CTC** и сохраняет текст. Казахский, русский,
английский. **Нажимать Record в Zoom не нужно. Аудио и видео не сохраняются.**
В основном режиме нет RTMS, облачного STT, внешней LLM, подписки приложения
или расхода Zoom API credits.

Помощник работает на вашем ПК рядом с обычным Zoom Workplace. Бот не
присоединяется. Zoom Marketplace, OAuth и загрузка кода на сервер Zoom не нужны.
Обычные расходы существующего Zoom-плана, интернета и электричества приложение
не отменяет; новых платных сервисов оно не вызывает.

**Ранее проверено (до замены способа установки):** настоящий выход Windows → GigaAM → пять экспортов на публичной
KK/RU/EN речи. На i5‑10300H/8 ГБ: пик RSS около 1,9 ГБ, CPU в среднем 12,17%,
задержка готовых реплик 2,44–6,02 с, пропусков нет в одном коротком прогоне.
**Реальная Zoom-встреча пока не подтверждена.** Подписи говорящих вероятностные,
не настоящие Zoom ID. [Методика и ограничения](docs/DESKTOP_TESTING.md).

## Запуск на Windows / из IDE

**Впервые запускаете из ZIP?** Начните с [пошаговой инструкции для Windows, Microsoft Visual Studio и VS Code](docs/WINDOWS_ZIP_VISUAL_STUDIO.md): скачивание без клонирования, установка, модель, запуск и частые ошибки.

Нужны Python 3.12 или 3.13 x64 с Tcl/Tk и Windows 10/11. **Git и Hugging Face не нужны.**
Скачайте **Code → Download ZIP** из этого репозитория, распакуйте архив и откройте
терминал в папке с `app.py`. Затем:

```powershell
./setup.ps1
./.venv/Scripts/python.exe scripts/acquire_model.py --check
./.venv/Scripts/python.exe scripts/download_diarization.py
./start.ps1
```

`setup.ps1` устанавливает библиотеки и автоматически подготавливает GigaAM.
Следующая команда `--check` только проверяет локальные файлы без сети;
скачивание CAM++ необязательно. Для ручной установки или переноса весов
используйте пошаговую инструкцию выше.

Минимальный код GigaAM включён в `vendor/gigaam`, JSON, карточка модели и условия
MIT находятся в `assets/gigaam`. `huggingface_hub` и `transformers` не нужны.
Большие веса скачиваются отдельно только из [GitHub Release models-v1 этого репозитория](https://github.com/AssylbekGizatov/gigaam-zoom-transcriber/releases/tag/models-v1):
GigaAM около 900 МБ, необязательный CAM++ около 28 МБ. Они не входят в исходный ZIP
и не используют Git LFS. Это не полный офлайн-установщик: библиотеки один раз
загружаются с PyPI и CPU-индекса PyTorch.

Оба загрузчика поддерживают `--check` для проверки без сети и
`--source-directory ПАПКА` для разрешённого ручного переноса весов.
[Команды, ручная загрузка и корпоративная сеть](docs/WINDOWS_ZIP_VISUAL_STUDIO.md#6-скачать-модель-распознавания).
Автоматического возврата к Hugging Face нет.

Можно выбрать уже имеющиеся проверенные веса GigaAM. Загрузка весов выполняется
при подготовке через `setup.ps1` или отдельный загрузчик; во время сеанса модель
не скачивается. Если Windows блокирует
скрипт, выполните его команды в терминале IDE, не меняя политику безопасности.

**IDE:** открыть корень в VS Code/PyCharm → интерпретатор
`.venv/Scripts/python.exe` → Run **app.py**, рабочая папка — корень проекта.

## Корпоративный Windows: Python 3.13 без virtual environment

Если `.venv\Scripts\python.exe` блокируется Group Policy с WinError 1260,
используйте установленный разрешённый Python. `setup.ps1` и `start.ps1`
относятся к установке с `.venv`; для этого варианта они не нужны.
Для уже работающего приложения достаточно добавить OCR-пакеты:

```powershell
py -3.13 -m pip install --user -r requirements-zoom-ocr.txt -c constraints.txt
py -3.13 scripts/acquire_model.py --check
py -3.13 app.py
```

При чистой установке сначала установите CPU Torch и desktop-зависимости:

```powershell
py -3.13 -m pip install --user --index-url https://download.pytorch.org/whl/cpu torch==2.10.0+cpu torchaudio==2.10.0+cpu -c constraints.txt
py -3.13 -m pip install --user -r requirements-desktop.txt -c constraints.txt
py -3.13 scripts/acquire_model.py
```

Системные политики не изменяются. Если корпоративный Python не разрешает
установку пользовательских пакетов, используйте согласованный с IT каталог
пакетов. Модель по-прежнему берётся из GitHub Release `models-v1`.
Колёса OCR-зависимостей проверены на наличие для CPython 3.13 Windows x64;
это не заменяет запуск OCR и ASR на вашем компьютере.

Для Zoom 7.1.5, который не раскрывает смену говорящего в UIA, выберите режим
OCR и выделите **только отображаемое имя основного участника в Speaker View**.
Windows распознаёт эту область локально. Нужен установленный OCR-язык Windows.
[Настройка, ограничения и проверка имён](docs/ZOOM_SPEAKER_OCR.md).

## Разовая настройка

1. «Модель и помощь»: выбрать папку с `config.json` и `pytorch_model.bin` GigaAM.
2. «Встреча»: выбрать локальную папку для текста и экспорта.
3. Выбрать тот же выход звука, что используется в Zoom. Предпочтительны наушники.
4. При необходимости включить «Добавить мой микрофон» и указать своё имя.
5. Для реальных отображаемых имён настройте [OCR в Speaker View](docs/ZOOM_SPEAKER_OCR.md), если UIA недоступен. Diarization для этого не нужен.
6. Для необязательных «Говорящий 1, 2…» включить различение голосов; модель
   `models/diarization/campplus.onnx`. Это экспериментальная опция, которую
   можно выключить. [Полная инструкция](docs/DESKTOP_GUIDE.md).

## Каждый звонок

1. Войти в обычную встречу Zoom, подключить компьютерный звук, уведомить участников о транскрипции.
2. В нашем приложении нажать **«Начать» до разговора**, дождаться загрузки модели.
3. Наблюдать уровни звука, текст, подписи источников и сообщения о пропусках.
4. **«Стоп и завершить текст»** → экспорт TXT / Markdown / DOCX / PDF / JSON.
   Журнал можно открыть позднее и экспортировать снова.

Модель работает **во время звонка**, даже если документ нужен только в конце:
звука после встречи не остаётся. Сказанное до старта/в пропусках восстановить
без записи нельзя. Локальный захват микрофона **не следует mute-кнопке Zoom**.
Остановите приложение, чтобы прекратить его обработку.

## Кто говорит

| Подпись | Значение |
|---|---|
| Мой микрофон | Отдельный локальный источник, введённое вами имя. |
| По окну Zoom | Явная UIA-метка либо локальное OCR выбранной области имени в Speaker View; возможны задержки и ошибки. |
| По голосу | Необязательный локальный кластер похожих голосов, номер без установленной личности. |
| Не определён | Недостаточно данных для подписи. |
| Исправлено | Имя указано пользователем после встречи. |

ID **локальные, не Zoom ID**. WASAPI получает общий звук выбранного выхода,
включая другие приложения. Общий микрофон и одновременная речь не разделяются
надёжно. Имена не выводятся из голоса. JSON содержит `attribution`;
`status=final` относится к тексту, не к доказанной личности.

Очередь захвата ≤2 с, очередь распознавания ≤24 с. В окне последние 500 реплик,
весь текст постепенно сохраняется в локальном SQLite без отдельного сервера.
PCM остаётся только в RAM. Папка не шифруется приложением и может
синхронизироваться OneDrive средствами Windows.
