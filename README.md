# GigaAM · Живой текст Zoom

Windows-приложение получает **живой звук во время звонка**, распознаёт его
локальной **GigaAM Multilingual 220M CTC** и сохраняет текст. Казахский, русский,
английский. **Нажимать Record в Zoom не нужно. Аудио и видео не сохраняются.**
В основном режиме нет RTMS, облачного STT, внешней LLM, подписки приложения
или расхода Zoom API credits.

Помощник работает на вашем ПК рядом с обычным Zoom Workplace. Бот не
присоединяется. Zoom Marketplace, OAuth и загрузка кода на сервер Zoom не нужны.
Обычные расходы существующего Zoom-плана, интернета и электричества приложение
не отменяет; новых платных сервисов оно не вызывает.

**Проверено:** настоящий выход Windows → GigaAM → пять экспортов на публичной
KK/RU/EN речи. На i5‑10300H/8 ГБ: пик RSS около 1,9 ГБ, CPU в среднем 12,17%,
задержка готовых реплик 2,44–6,02 с, пропусков нет в одном коротком прогоне.
**Реальная Zoom-встреча пока не подтверждена.** Подписи говорящих вероятностные,
не настоящие Zoom ID. [Методика и ограничения](docs/DESKTOP_TESTING.md).

## Запуск на Windows / из IDE

**Впервые запускаете из ZIP?** Начните с [пошаговой инструкции для Windows, Microsoft Visual Studio и VS Code](docs/WINDOWS_ZIP_VISUAL_STUDIO.md): скачивание без клонирования, установка, модель, запуск и частые ошибки.

Нужны Python 3.12 x64 с Tcl/Tk, Git, Windows 10/11.

```powershell
git clone https://github.com/AssylbekGizatov/gigaam-zoom-transcriber.git
cd gigaam-zoom-transcriber
./setup.ps1
./.venv/Scripts/python.exe scripts/acquire_model.py
./.venv/Scripts/python.exe scripts/download_diarization.py
./start.ps1
```

Можно выбрать уже имеющиеся проверенные веса GigaAM. Загрузка весов — отдельное
явное действие; во время сеанса модель не скачивается. Если Windows блокирует
скрипт, выполните его команды в терминале IDE, не меняя политику безопасности.

**IDE:** открыть корень в VS Code/PyCharm → интерпретатор
`.venv/Scripts/python.exe` → Run **app.py**, рабочая папка — корень проекта.

## Разовая настройка

1. «Модель и помощь»: выбрать папку с `config.json` и `pytorch_model.bin` GigaAM.
2. «Встреча»: выбрать локальную папку для текста и экспорта.
3. Выбрать тот же выход звука, что используется в Zoom. Предпочтительны наушники.
4. При необходимости включить «Добавить мой микрофон» и указать своё имя.
5. Для «Говорящий 1, 2…» включить различение голосов; модель
   `models/diarization/campplus.onnx`. Это экспериментальная опция, которую
   можно выключить. [Полная инструкция](docs/DESKTOP_GUIDE.md).

## Каждый звонок

1. Войти в обычную встречу Zoom, подключить компьютерный звук, уведомить участников о транскрипции.
2. В нашем приложении нажать **«Начать» до разговора**, дождаться загрузки модели.
3. Наблюдать уровни звука, текст, подписи источников и сообщения о пропусках.
4. **«Стоп и завершить текст»** → экспорт TXT / Markdown / DOCX / PDF / JSON.
   Журнал можно открыть позднее и экспортировать снова.

Модель работает **во время звонка**, даже если документ нужен только в конце:
звука после встречи не остаётся. Сказанное до старта/в пропусках восстановить
без записи нельзя. Локальный захват микрофона **не следует mute-кнопке Zoom**.
Остановите приложение, чтобы прекратить его обработку.

## Кто говорит

| Подпись | Значение |
|---|---|
| Мой микрофон | Отдельный локальный источник, введённое вами имя. |
| По окну Zoom | Экспериментальная подсказка из явной accessibility-метки говорящего; возможны задержки и ошибки. |
| По голосу | Необязательный локальный кластер похожих голосов, номер без установленной личности. |
| Не определён | Недостаточно данных для подписи. |
| Исправлено | Имя указано пользователем после встречи. |

ID **локальные, не Zoom ID**. WASAPI получает общий звук выбранного выхода,
включая другие приложения. Общий микрофон и одновременная речь не разделяются
надёжно. Имена не выводятся из голоса. JSON содержит `attribution`;
`status=final` относится к тексту, не к доказанной личности.

Очередь захвата ≤2 с, очередь распознавания ≤24 с. В окне последние 500 реплик,
весь текст постепенно сохраняется в локальном SQLite без отдельного сервера.
PCM остаётся только в RAM. Папка не шифруется приложением и может
синхронизироваться OneDrive средствами Windows.
