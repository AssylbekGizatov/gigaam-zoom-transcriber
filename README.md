# GigaAM · Живой текст Zoom

Приложение для Windows получает звук встречи через WASAPI, распознаёт его
локальной GigaAM и связывает слова с отображаемым именем в Zoom Speaker View.
Имя читается из изображения окна встроенным Windows OCR. Модели определения личности по
голосу, Zoom API, облачный STT и платные сервисы не используются.
В обычной работе аудио, видео и снимки экрана в файлы не сохраняются.

Целевая среда: **Windows 11, Python 3.13 x64, Zoom Workplace 7.1.5 (43453)**.
Используется разрешённый системный Python; virtual environment, Git и права
администратора для запуска приложения не нужны. Исходники можно скачать через
**Code → Download ZIP** и распаковать в обычную локальную папку.

## Установка

Откройте обычный **CMD** в папке с `app.py`. Установите все зависимости одной
командой; она включает CPU PyTorch, WASAPI, Windows OCR и локальный код GigaAM:

```bat
py -3.13 -m pip install --user -r requirements-desktop.txt
```

Первичная установка обращается к PyPI и CPU-индексу PyTorch. Она не использует
Hugging Face. Если политика компании запрещает установку пакетов в профиль
пользователя, потребуется разрешённый IT способ доставки этих же зависимостей.
Не нужно менять Group Policy или запускать `.venv\Scripts\python.exe`.

Если GigaAM уже установлена, проверьте её без сети:

```bat
py -3.13 scripts/acquire_model.py --check
```

Если весов ещё нет:

```bat
py -3.13 scripts/acquire_model.py
```

Загрузчик берёт `pytorch_model.bin` только из
[GitHub Release models-v1](https://github.com/AssylbekGizatov/gigaam-zoom-transcriber/releases/tag/models-v1)
и проверяет SHA256. Конфигурация, карточка и лицензия входят в исходники.
Автоматического обращения к Hugging Face нет. Разрешённый ручной перенос:
`py -3.13 scripts/acquire_model.py --source-directory "C:\ApprovedModels"`.

## Запуск

```bat
py -3.13 app.py
```

Либо дважды нажмите **Start_GigaAM.cmd**. Он запускает ту же команду из папки
приложения, не создаёт окружение и не устанавливает зависимости автоматически.

## Настройка встречи

1. Войти в Zoom, включить компьютерный звук и надеть наушники. В приложении
   выбрать тот же выход звука и локальную папку результатов.
2. В Zoom включить **Speaker View** и показ имён. Убрать закрепление (pin),
   spotlight и демонстрацию экрана: главное видео должно автоматически
   переключаться на говорящего.
3. Выбрать установленный язык Windows OCR, например `ru` или `en-US`.
   Выделить область **только строки имени основного участника** по подсказкам
   приложения. Оставить поля вокруг букв и место для длинного имени.
4. Проверить условия Speaker View и нажать «Начать» до разговора.
   Оставить Zoom развёрнутым. При успешном WGC/PrintWindow другое приложение
   может перекрывать его; резервный screen DC требует видимой области имени.
   Текст появляется после обработки небольших буферов.
5. Нажать «Стоп и завершить текст». Экспортировать DOCX, PDF или TXT. Сеанс SQLite можно открыть и экспортировать позднее.

Подробная [инструкция чтения имён и диагностики](docs/ZOOM_SPEAKER_OCR.md).
OCR-язык должен уже быть установлен в Windows; приложение его не скачивает.

## Что означает подпись

| Источник | Значение |
|---|---|
| OCR окна Zoom | Отображаемое имя, повторно прочитанное в настроенной области Speaker View. |
| Восстановлено по соседним репликам | Короткий пропуск между двумя совпадающими прямыми подписями; отдельно помечен в тексте и экспорте. |
| Мой микрофон | Ваш отдельный локальный источник и введённое вами имя; включается по желанию. |
| Неизвестно | Недостаточно свежих или однозначных наблюдений. |
| Исправлено | Имя указано пользователем для конкретной реплики после встречи. |

Имена привязываются ко времени звука, а не к моменту завершения ASR.
Подтверждённые OCR-наблюдения оцениваются с небольшим запасом до и после
слова, чтобы учесть задержку Speaker View. Конфликтующее позднее имя,
недостаточная поддержка, тишина или известное наложение дают «Неизвестно».
История для принятой очереди аудио сохраняется до обработки. Короткий
пропуск между одинаковыми прямыми подписями может быть отдельно помечен
как восстановленный; это не непосредственное наблюдение внутри пропуска.

**OCR не гарантирует правильную связь при любых настройках Zoom.** Переключение
Speaker View запаздывает, одинаковые имена неразличимы, OCR может ошибаться в
буквах. Pin/spotlight, Gallery View и screen sharing для этого режима не
поддерживаются. Относительная область следует за размером окна; существенная смена его
пропорций или компоновки требует повторной калибровки. Перекрытое окно читается через WGC или PrintWindow; при отказе обоих
резервный захват с экрана используется только для неперекрытой области.
Свёрнутый Zoom не поддерживается. Звук и ASR продолжают работу при отказе
чтения имён. Передний план Zoom не обязателен. Два удалённых голоса в одном миксе при неизменном имени
на экране неразличимы для этого метода; общий микрофон также не разделяется.

WASAPI принимает весь звук выбранного выхода, включая другие приложения.
Локальный микрофон, если включён, не следует кнопке mute в Zoom. Оповестите
участников о транскрипции и остановите остальные источники звука на этом выходе.

## Проверка и документация

Пользователь подтвердил стабильный запуск предыдущего исправления
`f5f7497` на Windows `10.0.26100.9974`. Новый оконный захват и привязка имён
ещё требуют отдельной проверки в реальной Zoom-встрече. Автотесты не заменяют встречу с двумя
попеременно говорящими удалёнными участниками.

py -3.13 -m pip install --user -r requirements-dev.txt -c constraints.txt
