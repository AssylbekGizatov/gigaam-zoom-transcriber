# Приёмка Windows 11 и Zoom 7.1.5

Целевая машина: **Windows 11 `10.0.26100.9974`, Zoom Workplace `7.1.5 (43453)`,
Python 3.13 x64**. Запуск: `py -3.13 app.py` или `Start_GigaAM.cmd`. Проверка
в этой среде должна быть выполнена отдельно; Linux unit tests не подменяют её.

Предыдущая диагностика пользователя на Windows `10.0.26100.9711` обнаружила
семь окон Zoom, превышение лимита accessibility-обхода и отсутствие изменений
свойств восьми элементов при смене говорящего. Новая реализация читает видимое
имя через Windows OCR и не зависит от accessibility-метки говорящего.

## Повторный запуск после калибровки

На версии `cef5fbe` пользователь проверил установку пакетов, модель, мастер,
выбор области и сохранение настроек на Windows 11 10.0.26100.9974,
Python 3.13.11 x64 и Zoom 7.1.5.43453 (1920×1080, 96 DPI).
После первого успешного запуска процесс завершался с `0xC0000005` или
`0xC0000409`. Это происходило также с закрытым Zoom и без файла настроек.
При запуске без фонового сбора сведений о Windows окно открывалось.
Точную нативную функцию, в которой происходил сбой, установить не удалось.

Для проверки исправления распакуйте новый ZIP в отдельную папку. Откройте
в ней обычный CMD. Для десяти запусков достаточно уже установленных пакетов.
Качество имён и транскрипции проверяется в следующем разделе на живой встрече.

**Сохраните калибровку.** Закройте GigaAM. В этом сценарии исходный файл уже
содержит рабочую область и язык `en-US`. Если его ещё нет, сначала пройдите
калибровку. В одном окне CMD выполните команды и проверьте успешное копирование.

```bat
set "GIGAAM_CFG=%LOCALAPPDATA%\GigaAMZoom\desktop-settings.json"
set "GIGAAM_RETEST=%TEMP%\GigaAM-retest-%RANDOM%-%RANDOM%"
mkdir "%GIGAAM_RETEST%"
copy /b "%GIGAAM_CFG%" "%GIGAAM_RETEST%\original.json"
echo %GIGAAM_RETEST%
```

| Запуски | Zoom | Действие перед каждым запуском |
|---|---|---|
| 1–3 | Полностью закрыт, включая значок в трее | Восстановить настройки |
| 4–6 | Открыта встреча в Speaker View | Восстановить настройки |
| 7–8 | Полностью закрыт | Временно убрать настройки |
| 9–10 | Открыта встреча в Speaker View | Временно убрать настройки |

Для запусков **1–6** выполните:

```bat
copy /b /y "%GIGAAM_RETEST%\original.json" "%GIGAAM_CFG%"
```

Для запусков **7–10** перед каждым стартом перемещайте рабочую копию:

```bat
if exist "%GIGAAM_CFG%" move /y "%GIGAAM_CFG%" "%GIGAAM_RETEST%\last-test-settings.json"
```

Для каждого запуска выполните `py -3.13 app.py`. При одном из запусков
используйте `call Start_GigaAM.cmd`. Дождитесь статуса Zoom и языка OCR,
оставьте окно открытым 10 секунд и закройте его крестиком. При сохранённой
конфигурации проверьте `en-US` и ранее выбранную область. При пустой конфигурации
должен открыться мастер с языком `ru`, если он установлен. Сразу после
закрытия введите отдельной строкой `echo %ERRORLEVEL%`. Запишите номер запуска
и результат. Ожидаются десять штатных завершений с кодом `0`.

**Верните исходные настройки** после закрытия приложения, также если проверку
пришлось прервать:

```bat
copy /b /y "%GIGAAM_RETEST%\original.json" "%GIGAAM_CFG%"
fc /b "%GIGAAM_RETEST%\original.json" "%GIGAAM_CFG%"
```

При сбое запишите код выхода и время. Откройте журнал кнопкой «Открыть логи»
или командой `explorer "%LOCALAPPDATA%\GigaAMZoom\logs"`.
В `app.log` найдите текущий `session` и события `gui_mapped`,
`windows_environment`, `environment_probe_complete`. При аварии отдельного
процесса ищите `ocr_worker_crashed` и числовой `exit_code`; главное окно
должно оставаться доступным. В `crash.log` последняя метка той же сессии
показывает, к какому шагу успел перейти запуск. Стек записывается в очищенном
виде, когда Windows вызывает обработчик аварии. При fail-fast может остаться
только метка. Включённый вручную подробный OCR-журнал может содержать имена.

## Подготовка

1. Из чисто распакованного ZIP выполнить единственную команду установки:
   `py -3.13 -m pip install --user -r requirements-desktop.txt`.
2. Проверить существующую модель: `py -3.13 scripts/acquire_model.py --check`.
3. Запустить `py -3.13 app.py` без `.venv`, Git и прав администратора.
4. Пройти первый запуск: папка модели, установленный OCR-язык, проверка Zoom,
   выбор строки имени и локальной папки экспорта. Проверить сообщения при
   отсутствии модели, окна Zoom, языка или области.
5. Встреча — три участника, наушники. Локальный пользователь молчит;
   два удалённых участника A/B говорят по очереди. Speaker View без pin,
   spotlight, Gallery View и демонстрации экрана. На выбранном выходе нет
   музыки, уведомлений и других приложений со звуком.

## Сценарии

| Проверка | Ожидаемый результат / измерение |
|---|---|
| A говорит 10–15 с, пауза 3 с, B 10–15 с; повторить 5 раз | В середине фраз видимое имя соответствует подписи. Отдельно считать верные, неверные и unknown слова. |
| Переключение A → B без паузы, короткие реплики | Слову нужны совпадающие наблюдения до и после него в одном слышимом участке; конфликт/недостающая сторона дают «Неизвестно». Измерить задержку и ошибочные присвоения прошлого имени. |
| Переименовать B в C в Zoom | Подтверждённые новые наблюдения используют C; старые реплики не переписываются. |
| Кириллица, латиница, длинная подпись | Сравнить буквы; обрезанное или многострочное имя не принимать за полное. |
| Одинаковые имена A/B | Отметить ограничение: OCR не различает людей по одной и той же строке. |
| 10 с тишины, имя Zoom осталось на экране | Имя не переносится через тишину. При отсутствии активности подпись «Неизвестно»; не должно появляться выдуманного текста. |
| Закрыть подпись другим окном, свернуть Zoom | Имя сбрасывается/становится неизвестным, ASR остаётся работоспособным. |
| Убрать перекрытие | Новое имя появляется после подтверждения; пропущенное время не заполняется задним числом. |
| Изменить размер Zoom, монитор или DPI 100/125/150% | Относительная область следует за окном, имя подтверждается заново. При изменении пропорций >12% требуется калибровка. Проверить фактическое совпадение области со строкой имени. |
| Выключить показ имён, выбрать пустую область | Причина отображается, прошлое имя не удерживается бесконечно. |
| Отсутствует OCR-язык / повреждена зависимость | Понятное сообщение; нет автозагрузки модели OCR и падения аудиосеанса. |
| Известное наложение: локальный микрофон + удалённый звук, пересекающиеся таймкоды слов | Удалённые слова в таком конфликте получают «Неизвестно». |
| Два удалённых голоса A+B, имя на экране стабильно | Это нераспознаваемое наложение в общем миксе: правило может дать неверное имя. Отметить ограничение; не ожидать гарантированного автоматического «Неизвестно». |
| Pin/spotlight/Gallery View/share | Не поддерживаются; чтение имён нужно отключить/перенастроить. Не заявлять автоматическое обнаружение по одним пикселям имени. |
| Stop во время OCR, закрытие Zoom | Остановка ограничена по времени, сохранённый текст доступен экспорту. |
| DOCX / PDF / TXT в интерфейсе | Имена, время и происхождение подписи сохранены, кириллица читается. |
| Перезапуск приложения | Настройки сохраняются, предыдущий SQLite читается; новый сеанс не наследует имя старой встречи. |
| Папка приложения и результатов | Нет созданных кадров/аудио/видео; остаются только настройки, локальная диагностика и текстовые результаты. |

Проверить также запуск двойным нажатием `Start_GigaAM.cmd` из каталога с пробелами,
отмену первого запуска, выход во время загрузки модели и отключение USB-наушников.

## Отчёт

Запишите версии Windows/Zoom/Python, OCR-языки, DPI, размер клиентской области,
агрегированное число верных/неверных/неподписанных слов и сообщения ошибок.
Точные частные имена, реплики, кадры и аудио не нужны для публичного отчёта.

Доля подписанных слов — покрытие, а не точность. Успешный один короткий прогон
не доказывает корректность длинных встреч, одновременной речи и всех компоновок
Zoom. Исторические данные ASR доступны в [TESTING](TESTING.md); новый результат
нужно фиксировать отдельно, не заменяя им старый отчёт.


Для серии A/B посчитайте:

- `correct_rate = correct / total`, доля слов с правильной подписью;
- `wrong_rate = wrong / total`, доля слов с неправильной подписью;
- `unknown_rate = unknown / total`, доля слов без подписи;
- задержку от фактического начала речи B до первого подтверждённого имени B:
  минимум, медиану, максимум и число переключений.

`total = correct + wrong + unknown`; слова с наложением голосов учитывайте
отдельной серией. Не вычисляйте «точность» как число любых подписанных слов.
Сначала проверить говорящего A, затем B и повтор A; отдельно — A+B одновременно,
демонстрацию экрана (screen sharing) и свёрнутый Zoom (minimized).
