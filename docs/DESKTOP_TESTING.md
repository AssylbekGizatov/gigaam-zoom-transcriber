# Проверка живого настольного режима

4 ноября 2026, Asia/Qyzylorda. `app.py` версии 0.2. **Реальная Zoom-встреча
не подтверждена.** Этот отчёт не подменяет её локальным тестом.

## Настоящий звук Windows и настоящая GigaAM

`scripts/evaluate_desktop.py` проигрывает разрешённые WAV в реальном времени
через настоящий Windows output. WASAPI loopback принимает сигнал, stateful
resampler выдаёт mono PCM16/16 kHz, Pipeline/GigaAM распознают слова, SQLite
сохраняет текст, пять экспортов создаются и повторно читаются. Модель настоящая.
Захваченный звук не записывается; исходные публичные WAV существовали ранее.

[Машинный отчёт](evidence/desktop-loopback.json). В первом прогоне микрофон,
UIA и кластеризация голосов отключены. Python socket egress блокируется,
0 попыток. Это не системный firewall-аудит нативных библиотек.

Windows 11 build 26200, i5‑10300H 4/8 CPU, 8029 MiB RAM, Python 3.12.3,
Torch/Torchaudio 2.10 CPU, PyAudioWPatch 0.2.12.8. GTX 1650 не использовалась.
Компьютер не изолирован от пользовательской нагрузки.

## Capture и исправления по аппаратному тесту

`scripts/probe_desktop_audio.py`: EN 5,855 с → 6,86 с с паузами, 343 пакета,
max RMS 0,394, 0 dropped/overflow, очередь 0,02 с. Выявлена потеря начала
после idle WASAPI; добавлен тихий shared renderer, повтор дал непрерывную шкалу.
Позже clock исправлен для driver stall >250 мс: пропущенное время не сжимается,
растёт счётчик clock_discontinuities, FIR начинает новый непрерывный участок.
Регрессия покрыта тестом. Финальный интеграционный прогон указан отдельно ниже.

## Голоса

[Отдельный реальный ONNX-прогон](evidence/desktop-diarization.json): WeSpeaker,
один поток CPU, 48,305 с публичной речи KK/RU/EN/повтор KK, 8,091 с обработки,
RTF 0,1675, пик RSS около 111 MiB (при загрузке 118 MiB). Доминирующие кластеры
трёх исходных файлов различились, повтор того же KK использовал прежний номер.

**Это калибровка на этих же примерах, не независимая оценка качества.**
Начальная настройка объединяла KK/RU; пороги и окно изменены по результатам
этих данных. Остались неизвестные участки. Нет независимо измеренного DER,
подтверждения личности или теста естественного overlap. Модель голосов —
экспериментальная opt-in функция, по умолчанию выключена.

### Финальные интеграционные прогоны голосов

WeSpeaker в [настоящем loopback](evidence/desktop-loopback-diarization.json)
объединила KK/RU: два кластера вместо трёх. Изолированная калибровка не
перенеслась на изменившиеся границы живых окон. Этот неудачный результат
сохранён, модель не выбрана основной.

**CAM++** выбран основным вариантом опции после отдельного
[WASAPI → GigaAM → CAM++ прогона](evidence/desktop-loopback-campplus.json).
Прошли пять экспортов, нет dropped/overflow/clock discontinuities, нет
Python network attempts. GigaAM дала те же WER: KK/RU 0%, EN 1/17 правка.
ASR+голоса: 13,62 с на 28,725 с речи, RTF 0,474; средний CPU 11,94%,
пик RSS включая загрузку 1961,36 MiB. Задержки частей реплик 3,63–10,60 с.

Каждый из трёх исходных файлов получил собственный кластер без объединения с другим файлом,
но метку получили только **34/52 слова (65,4%)**: KK 1/9, RU 20/26, EN 13/17.
Остальные слова оставлены unknown. **Это покрытие, не точность 65,4%.**
Выбор модели также сделан на этих примерах, независимого held-out DER нет.
На реальных разговорах возможны и объединения, и дробление голосов.
Надёжная атрибуция каждого говорящего пока не достигнута.
Полные параметры/лицензия/ограничения — [DIARIZATION.md](DIARIZATION.md).

## Экспорт, интерфейс, автоматические проверки

Финальный локальный прогон: **214 тестов прошли за 33,46 с**.

TXT/MD/JSON повторно прочитаны, DOCX — через OOXML, PDF — через pypdf; содержат
текст и метаданные. Это проверка содержания, а не новый render-аудит каждой
страницы. Ранее DOCX/PDF с казахскими символами визуально проверялись — TESTING.md.
Настоящее Tk-окно открыто на Windows, визуально проверены устройства, старт/
стоп, индикаторы, таблица, экспорт. Открытое окно не доказывает Zoom-интеграцию.

Добавлены тесты: downmix/resampling, clock gaps, bounded queues, отказы устройств,
UIA missing/stale/ambiguous/late, одинаковые имена/rename, границы слов,
bounded histories, voice clusters на fake embeddings, lifecycle/отмена/restart,
ошибки диска/модели, partial при последнем потерянном блоке, provenance,
миграция SQLite, ручные подписи, пять экспортов, настройки и отсутствие socket egress.
CI Windows/Linux не использует Zoom-аккаунт и не скачивает модели. Фиктивные
движки в unit tests не выдаются за настоящие акустические проверки.

Старый ускоренный восьмичасовой soak проверял Pipeline/Store с fake ASR.
Он не является восемью часами настоящего WASAPI/Zoom. Многочасовой аппаратный
прогон нового режима ещё не выполнен.

## Незакрытая приёмка

- Настоящая Zoom-встреча с 2–3 отдельными источниками и известными фразами.
- Реальные UIA-метки Zoom, rename/rejoin, одинаковые имена и смена говорящего.
- Микрофон одновременно с Zoom, динамики/эхо, Bluetooth hotplug.
- Естественная смешанная речь, overlapping speakers, многочасовая нагрузка.

Установленный Zoom Workplace 7.1.9 находился на экране входа. Авторизация
не автоматизировалась; у владельца запрошены ручной вход и отдельная тестовая
встреча. RTMS, покупки и новые платные потоки не включались. Статус нужно
дополнить фактическим evidence, когда доступна встреча.

## Приёмка OCR на Windows 11 и Zoom 7.1.5

Целевая среда, сообщённая пользователем: Windows 11 `10.0.26100.9711`,
Zoom Workplace `7.1.5 (43453)`, Python 3.13 x64. В этой среде пользователь
обнаружил `uia_scan_incomplete` при семи окнах Zoom и `uia_missing` для одного
Zoom Meeting. ControlViewWalker и RawViewWalker возвращали восемь элементов,
без изменений проверяемых свойств при попеременной речи двух удалённых
участников в Speaker View. Это исходные данные пользователя, а не новый прогон.

Новый OCR-путь необходимо принять на этой машине. Наличие Windows wheels и
прохождение синтетических тестов не подтверждают его работу с настоящим Zoom.
Используйте [инструкцию OCR](ZOOM_SPEAKER_OCR.md). Запуск — `py -3.13 app.py`,
без `.venv`; модели — уже установленные из GitHub Release `models-v1`.

Условия: три участника, наушники, два удалённых говорящих A/B, локальный
участник молчит. Различение голосов выключено. Windows OCR-язык установлен,
выделена только строка имени основного Speaker View. Без pin/spotlight,
Gallery View, share, уведомлений и другого звука на том же выходе.

| Проверка | Ожидаемый результат / что зафиксировать |
|---|---|
| A говорит 10–15 с, пауза 3 с, B говорит 10–15 с; повторить 5 раз | В устойчивой середине фраз видимое имя совпадает с подписью. Записать число верных/неверных/unknown слов и задержку переключения. |
| A → B без паузы, затем короткие реплики | Граница может остаться unknown; не обещать полноту имён. Отдельно считать ошибочное присвоение прошлого имени. |
| Латинское и кириллическое имя, длинное имя | Сравнить буквы вручную. Обрезанное/многострочное имя не должно считаться полным. |
| Переименование B в C в Zoom | Новые подтверждённые наблюдения используют C и другой локальный ID; старый текст не переписывается. |
| Одинаковые имена A/B | Зафиксировать ограничение: OCR не различает людей по одинаковой строке. |
| 10 с тишины после речи | Не должно появляться выдуманного текста; сохранённое Zoom имя не доказывает речь в тишине. |
| Переключиться на транскрибатор/другое приложение, свернуть Zoom | Новые слова после потери наблюдений остаются без имени. Аудио и текст продолжают работать. |
| Вернуть Zoom на передний план | Новое имя только после повторного подтверждения, без заполнения пропущенного периода задним числом. |
| Переместить окно на монитор с другим DPI; изменить размер/панели | Проверить отказ при невалидной геометрии; повторить калибровку. Не принимать чужую строку за имя. |
| Убрать показ имён, выбрать неверную/пустую область | Диагностика и unknown, старое имя не удерживается бесконечно. |
| Неустановленный язык OCR / отсутствующий WinRT | Понятная диагностика, без скачивания моделей и падения ASR. |
| Pin, spotlight, Gallery View или share | Эти режимы не поддерживаются; пользователь должен выключить OCR. Не считать отрицательный тест доказательством автообнаружения режима. |
| Одновременная речь | Зафиксировать ограничение смешанного аудио; не принимать подпись за доказанное разделение голосов. |
| Stop во время OCR, закрытие Zoom | Остановка ограничена по времени, сохранённый текст доступен. |
| TXT / MD / DOCX / PDF / JSON | Имена и источник атрибуции сохранены, JSON содержит локальный ID и attribution. |
| Папка результатов и настройки | Нет созданных приложением PNG/JPG/аудио/видео; только текст, SQLite и настройки. |

Не публикуйте имена участников и их частные реплики. В отчёте достаточно
сборок ПО, OCR-языка, DPI, параметров области, агрегированных ошибок и кодов
диагностики. Настоящий процент правильных имён можно заявлять только по такому
размеченному прогону; доля подписанных слов не равна точности атрибуции.
