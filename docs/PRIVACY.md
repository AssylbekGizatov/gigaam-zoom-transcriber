# Приватность локального теста

PCM находится в ограниченных RAM-буферах и не записывается приложением на диск.
Распознанный текст, Zoom IDs, имена, время, смены участников и gaps сохраняются
в SQLite в явно выбранной папке. TXT/MD/DOCX/PDF/JSON появляются по явному экспорту.
Файлы экспорта не перезаписываются. SQLite сам по себе не шифрует содержание.
Файл, WAL/SHM, резервные копии и экспорты нужно учитывать в вашей политике хранения.

Настройки и encrypted credentials лежат в `%LOCALAPPDATA%/GigaAMZoom`.
Client Secret и OAuth access/refresh tokens шифруются Windows DPAPI в scope
текущего пользователя. Пароли Zoom не запрашиваются. Приложение не выводит
HTTP error bodies и подписанные URL в диагностические сообщения.
Защита DPAPI не защищает от программы с правами того же пользователя или от
компрометации Windows. Секреты в RAM нужны для подключения Zoom.

Основной режим `websocket` использует сеть только для Zoom OAuth/REST/WSS и
обычного Zoom; первоначальная загрузка модели выполняется отдельно. События
RTMS и PCM поступают непосредственно от Zoom. Внешний HTTPS forwarder, его аккаунт
и публичный входящий endpoint для этого режима не нужны. Event WebSocket
использует краткоживущий токен в RAM; URL подписки и URL с токеном нельзя
публиковать в GitHub, скриншотах или логах.

Четыре согласованных scopes ограничены audio RTMS, Start/Stop, профилем
подключённого пользователя и списком его встреч. Public Client PKCE и сохранение
трёх lifecycle events не разрешают расходовать кредиты или включать auto-start.
«Проверить события Zoom» открывает только канал событий, не запускает RTMS и не
отправляет аудио на распознавание.

В резервном режиме `webhook` отдельно выбранный HTTPS forwarder получает
метаданные встречи/аккаунта/оператора, stream ID, server URLs, timestamps и
подписанные заголовки. PCM и текст через него не проходят. Поставщик и его условия
требуют отдельного выбора и согласия; не включайте запись payload в инспекторе
туннеля. Внешнее распознавание и телеметрия приложения не используются.
Результаты локальной проверки блокировки сетевых попыток модели в TESTING.md
не являются системным сетевым аудитом всех программ.

Папка OneDrive/Dropbox/сетевой диск может отправлять файлы в облако средствами ОС.
Выбирайте локальный несинхронизируемый каталог. Память может попадать в paging
или crash dump ОС. Это приложение не меняет Windows security/privacy настройки.

Zoom consent/revoke не заменяет согласие участников. При revocation приложение
останавливает поток; уже созданные файлы, копии и экспорты необходимо удалить
в соответствии с требованиями встречи и Zoom. Автоматическая проверенная очистка
всех копий пока не реализована; сценарий отзыва доступа входит в обязательный
приёмочный тест. Для опубликованного/организационного продукта такая граница
недостаточна — текущий проект предназначен для согласованного личного Local Test.

В репозиторий не включаются модель, аудиофайлы, реальные транскрипты, SQLite,
токены, настройки и секреты. Публикуются только код, лицензии, синтетические
тесты и результаты разрешённых публичных аудиопроверок с атрибуцией.
