# Данные и приватность

Во время встречи приложение получает общий звук выбранного WASAPI-выхода,
дополнительно — локальный микрофон, если он включён. Микрофон не следует
mute-кнопке Zoom. Другие приложения на том же выходе также входят в микс.

GigaAM обрабатывает аудио локально. Windows OCR читает выбранную область
видимого имени Zoom. Калибровка показывает изображение для выбора области.
При обычной работе программа не сохраняет аудио, видео или скриншоты в файлы и не отправляет их
в облачный сервис. Изображения и PCM используются в RAM. Работа Windows swap,
crash dumps и системных компонентов находится вне контроля приложения.

В выбранной папке сохраняются SQLite с текстом/именами/таймкодами и созданные
пользователем экспорты. Локальные настройки содержат пути, выбранные устройства,
область и язык OCR. Диагностика не должна содержать кадры встречи, аудио и
личный текст. Перед передачей логов просмотрите их на своём компьютере.

Приложение не шифрует папку результатов. OneDrive, корпоративное резервное
копирование и другие средства Windows могут синхронизировать её независимо
от приложения. Выберите папку в соответствии с правилами организации и
уведомите участников о транскрипции.

Первичная установка библиотек использует PyPI и CPU-индекс PyTorch.
Явный загрузчик GigaAM использует GitHub Release `models-v1`, проверяет SHA256
и не обращается к Hugging Face. Сам сеанс не требует сетевого STT или OCR.
Zoom продолжает использовать свою обычную сеть для встречи.

OCR — наблюдение отображаемого имени, а не проверка личности. Совпадение имени
не доказывает, что говорил именно этот человек; возможны ошибки OCR, задержка
Speaker View, общий микрофон и одновременная речь.

CLI `probe_zoom_names.py --dump-ocr-text` по явному запросу печатает сырой
распознанный текст. `--save-debug-frame PATH` явно сохраняет один диагностический
кадр. Эти опции не включены в обычную работу и могут содержать частные данные.
