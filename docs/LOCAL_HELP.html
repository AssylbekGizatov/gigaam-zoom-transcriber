Живой текст встречи Zoom

Программа распознаёт звук компьютера локальной GigaAM и читает отображаемое имя в окне Zoom средствами OCR Windows. Аудио и снимки экрана не сохраняются.

Первый запуск

  1. Запустите py -3.13 app.py. Установка Git, виртуальная среда и запуск от администратора для программы не нужны.
  2. Если модель не установлена, нажмите Скачать модель. Файлы загружаются из GitHub Release models-v1 с проверкой контрольных сумм. Если модель уже есть, откройте Настройки → Папка….
  3. В Zoom выберите Speaker View, отключите Pin и Spotlight, включите постоянное отображение имён. Не используйте галерею и демонстрацию экрана для чтения имени.
  4. Выберите установленный язык OCR из списка. Для русских имён нужен русский OCR Windows; выбор языка распознавания речи GigaAM отдельно не требуется.
  5. Нажмите Выбрать область имени…. Выделите полное имя под главным видео, оставив место для длинных имён. Не захватывайте значки микрофона, кнопки и соседние плитки. Проверьте распознанное имя в предпросмотре и подтвердите область.
  6. Выберите тот же выход звука, который использует Zoom, и папку для текста. При необходимости включите Мой микрофон, выберите устройство и задайте своё имя.
  7. Нажмите Начать до разговора. После встречи нажмите Стоп и завершить текст, затем экспортируйте DOCX, PDF или TXT.
Без настроенной области имени транскрипция продолжает работать с подписью «Неизвестно». Имя с экрана может запаздывать и распознаваться с ошибками. Подпись слова требует совпадающего имени до и после слова в одном участке слышимой речи. Известный конфликт даёт «Неизвестно». Два удалённых голоса при неизменном имени на экране программа не различает. Если имя восстановлено по соседним репликам, это отдельно отмечено в экспорте и при исправлении имени. Проверьте имена перед экспортом; отдельную реплику можно исправить вручную. Ручная правка имеет приоритет.

Если имя не определяется

  • Zoom можно перекрыть другими окнами, если захват окна работает в вашей конфигурации. Если программа просит открыть область имени, уберите перекрывающее окно: запасной способ чтения использует видимые пиксели экрана. Не сворачивайте Zoom — свёрнутое окно не поддерживается. На двух мониторах можно разместить Zoom и транскриптор отдельно.
  • Область следует за размером окна; после изменения геометрии имя подтверждается заново. При существенной смене пропорций или расположения подписи выделите область повторно. После смены режима просмотра вернитесь к Speaker View и проверьте область.
  • Оставьте открытым одно окно встречи Zoom. Если текст в области обрезан или имя заканчивается многоточием, увеличьте область.
  • Если список языков пуст, проверьте установку зависимостей программы по README и доступность OCR в Windows: Параметры → Время и язык → Язык и регион → Параметры языка. На корпоративном компьютере установку языковых компонентов может выполнять ИТ-служба. Программа не скачивает языки Windows автоматически.
  • Кнопка Обновить повторно проверяет устройства, языки OCR и окно Zoom.

Звук и сохранение

Выход захватывает все приложения, которые звучат на выбранном устройстве. Наденьте наушники при включённом микрофоне, чтобы не распознавать голос собеседника повторно. При смене наушников остановите сеанс, обновите устройства и начните новый.

В выбранной папке сохраняется журнал текста SQLite. Кнопка Открыть прошлый сеанс… позволяет снова экспортировать текст. Показанные в окне 500 последних реплик — только часть просмотра; экспорт содержит весь сохранённый текст.

Диагностика

Открыть логи открывает локальную папку диагностики. Обычные логи содержат служебные события и ошибки. Подробные логи OCR могут содержать имена участников; включайте их для диагностики и проверяйте перед передачей. Аудио и снимки экрана в логи не записываются.

Если корпоративная сеть блокирует скачивание модели, ИТ-служба может передать проверенные файлы GitHub Release. Программа не использует Hugging Face как резервный источник. Во время транскрипции модели работают локально.
